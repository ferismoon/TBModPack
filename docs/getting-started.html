Install

  1. Install Prism Launcher.
  2. Get the True Bastards: Forced Relocation instance from the Discord #minecraft-server channel.
  3. Import the instance into Prism Launcher.
  4. Sign into your Minecraft account.
  5. Launch the instance and allow Packwiz to update it.

Need help?

Use the True Bastards Discord channel for the instance, server details, and support.
