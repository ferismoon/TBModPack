Install

  1. Download Prism Launcher.
  2. Install Prism Launcher.
  3. Log in to your Minecraft account.
  4. Click Add Instance.
  5. Select Import.
  6. Browse to and select the modpack ZIP downloaded from the Discord server.
  7. Once the instance is installed, launch it once so Packwiz can update the modpack to the current version automatically.
  8. Request whitelist access from Moonie by posting in the Minecraft server channel on Discord.

Need help?

Use the True Bastards Discord channel for the instance, whitelist requests, server details, and support.
