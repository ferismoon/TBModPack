Version 1.2

  • Retired Toolshed hammer recipes and REI entries in favour of Just Hammers; updated the fishing quest reward. Existing hammers remain usable.
  • Current development version.
  • Added Bushy Leaves Resource Pack.
  • Fixed missing GUI slot icons.
  • Updated Xaero's Icon Resource Pack.
  • Updated Cubic Sun & Moon Resource Pack.
  • Updated many mods to their latest available 1.20.1 versions.
  • Added Macaw's Windows.
  • Removed Local Voice Chat and Romana Roads.
  • Migrated the pack to Packwiz.
  • Updated mod downloads to use Modrinth where appropriate.
  • Removed problematic and obsolete recipes.
  • Removed five broken Create crushing recipes for unavailable Biomes We've Gone materials (Ametrine, Pervaded Netherrack, Anthracite, Lignite, and Emeraldite), clearing their invisible ingredients and outputs from REI. Mythic Upgrades Ametrine recipes are unaffected.
  • Fixed duplicate structure salt values.
  • Applied many additional small compatibility and quality-of-life fixes.
  • Added new pack artwork.
  • Added BetterEnd, Bosses of Mass Destruction, and the enhanced dragon fight.
  • Removed obsolete Eldritch End and Better End Island content.
  • Updated FancyMenu links to the True Bastards Discord channel.
  • Added the True Bastards website and documentation pages.

See the Mod Wikis page for links to mods and documentation. Pack updates are delivered through Packwiz.
