# True Bastards Homestead

A private modded Minecraft pack created for the **True Bastards Discord server**.

True Bastards Homestead is based on **Tokimi's Homestead**, expanded and customised for our own server with additional mods, structures, Create content, recipes, configuration changes and assorted questionable decisions.

The aim is to keep the relaxed homestead and exploration feel of the original pack while giving us considerably more things to build, automate, discover and inevitably break.

## What We've Added

Our version expands the original pack with:

- ⚙️ Expanded **Create** content and automation
- 🏚️ Additional structures and exploration
- 🌍 More world-generation content
- 🛠️ Custom recipes and balance changes
- 📜 KubeJS modifications
- 🔧 Server-specific configuration
- ✨ Various quality-of-life additions

The pack will continue to change as our server develops.

## Installation

**True Bastards members should use the provided Prism Launcher instance.**

You do **not** need to download or clone this repository manually.

The Prism instance automatically checks this repository for updates using **Packwiz** whenever Minecraft is launched.

If the pack has been updated, only the files that have changed will be downloaded before the game starts.

### New Players

1. Install **Prism Launcher**
2. Import the provided **True Bastards Homestead** instance
3. Sign into your Minecraft account
4. Launch **True Bastards Homestead**
5. Cause problems

Updates after the initial installation are automatic.

## Updating the Pack

This repository is the master Packwiz version of the modpack.

Changes pushed here are distributed automatically to players through Packwiz.

Players should therefore **not manually update mods through Prism** unless specifically asked to do so.
