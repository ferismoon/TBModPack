# True Bastards Homestead

A custom Minecraft modpack created for the **True Bastards** private server.

Based on **Tokimi's Homestead**, with additional mods, expanded Create content, structures, custom recipes and various tweaks for our server.

## Installation

This pack is configured and distributed through **Prism Launcher + Packwiz**.

**If you're a member of the server and need to install the pack, ask Moonie for the setup instructions.**

Please don't download or modify files from this repository directly.
